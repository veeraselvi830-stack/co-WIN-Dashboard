# CoWIN Dashboard

A responsive CoWIN Dashboard built using React.js.

## Features

* Fetches COVID-19 vaccination data using an API
* Displays vaccination coverage for the last 7 days
* Displays vaccination data by gender
* Displays vaccination data by age
* Shows a loading indicator while fetching data
* Displays a failure view when the API request fails
* Uses Recharts for data visualization

## Technologies Used

* React.js
* JavaScript
* HTML
* CSS
* Recharts
* REST API

## API

https://apis.ccbp.in/covid-vaccination-data

## How to Run

```bash
npm install
npm start
```
